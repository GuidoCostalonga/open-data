# Archivio del sito fabioscoccimarro.it

Copia d'archivio del sito storico di Fabio Scoccimarro (prima versione del maggio 2001, candidatura alla presidenza della Provincia di Trieste, con pagine salvate fino al 2011), recuperata dalla Wayback Machine di Internet Archive.

- Pagine: 365 file HTML, tutti i collegamenti interni funzionanti.
- Immagini e script: non sono contenuti nella cartella, vengono caricati direttamente da web.archive.org.
- Punto di ingresso: `index.html`, che porta a `2/index.html`.

## Consultazione

Il sito si apre all'indirizzo:

https://raw.githack.com/GuidoCostalonga/open-data/main/fabioscoccimarro.it/index.html

Il file `.nojekyll` nella radice del repository impedisce a GitHub Pages di nascondere le cartelle che iniziano con il trattino basso (`_pages`), se un giorno il repository venisse pubblicato con Pages.
